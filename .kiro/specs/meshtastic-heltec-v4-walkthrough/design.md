# Design

## Approach

Markdown-first Zensical walkthrough. One job per page. Live flasher and board behaviour are
the source of truth; docs start draft-accurate and tighten during setup.

## Stack

- Zensical + zensical-patina
- actionsforge `zensical-pages-deploy`
- Kiro steering/hooks + Cursor rules + AGENTS.md

## Reading order

Overview → Prerequisites → Identify → Bootloader → Flash → First boot → Configure → Phone app → Verify →
Troubleshoot → Reference.
